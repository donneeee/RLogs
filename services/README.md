# Services

Website services live separately from the desktop runtime and never trust
client-computed results without replaying the submitted canonical timeline.

- `submissions/` privately stores sealed `.rlog` artifacts, replays them with
  the matching game plug-in, and publishes safe parse projections and an
  automatically derived browse catalog. Exact-instance run groups preserve
  each observer's report, inventory participant-local evidence witnesses, and
  track uploader provenance independently from the characters inside the run.
  A derived cross-vantage reconciliation manifest commits personal-gameplay
  profile witnesses to their source artifact and event while one canonical
  event spine prevents duplicate combat accounting.
