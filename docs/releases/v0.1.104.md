rLogs v0.1.104 adds packet-proven target shield and break state to the Overlay Canvas.

- Shows the selected target's current and maximum shield from entity attribute `60050`, including an exact percentage when both values are present.
- Shows the game's `EBreakingStage` state from entity attribute `455` without inferring break state from damage or animation timing.
- Clears shield and break state on authoritative entity snapshots so stale values cannot carry between targets or scenes.
- Keeps the target-frame contract fail-closed and bumps its schema so older renderers cannot silently misread the new fields.
- Includes the permanent uploader rejection handling from v0.1.101+, which stops terminally rejected incomplete captures from retrying forever.
