# rLogs 0.1.61

## Reliable live-overlay controls

- Fixes repeated Hide actions becoming inert after the native overlay window
  was hidden and later reopened.
- Keeps manual visibility state owned by the desktop host while retaining a
  direct native-window fallback if host command dispatch fails.
- Preserves forced Reset as a separate destructive action: an active run is
  sealed locally with a manual-boundary blocker, cleared from the live meter,
  and excluded from automatic submission.
- Adds regression coverage for repeated Hide dispatches across a suspended
  WebView lifecycle.
