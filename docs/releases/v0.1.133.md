# rLogs v0.1.133

## Highlights

- Adds a manual 1–6 marker XYZ editor to the overlay, with Save for deliberate overwrite and Save As for multiple named setups.
- Scopes marker presets to the active scene family, so one setup can cover a dungeon's M1–M20 variants without appearing in unrelated scenes.
- Previews saved presets locally on the real Mechanics Map with high-contrast numbered rings before any native placement capability is enabled.
- Adds canonical-time viewport zoom to the website combat graph while preserving global 1s, 5s, 10s, cumulative eDPS/aDPS/rDPS values and exact fractional run endpoints.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): 24687926
- Public report schema: 15 (unchanged); public reconciliation schema 18 (unchanged)

## Capability status

- Available: Manual marker preset authoring, Save, Save As, exact-context persistence, scene-family filtering, and host-session local preview on the Mechanics Map; website graph viewport selection, reset, bounded playback/navigation, and canonical at-time DPS variants.
- Locked: Reading the game's currently placed markers and transmitting a saved preset as in-game party markers. Both remain disabled until the current-build packet identity and an end-to-end safe placement path are proven.

## Known limitations

- Preview draws markers only in the local rLogs overlay; it does not place or change markers in the game for party members.
- Presets must currently be entered manually because capture-current is locked.
- A preview is bound to the current host session and exact build/scene/map/family context, expires after five minutes, and is cleared when its context is stale or malformed.
- Website graph zoom changes only the visible time range; DPS and rDPS denominators remain tied to the full canonical run clock rather than being rebased to the selected viewport.
