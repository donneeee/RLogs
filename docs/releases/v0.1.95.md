rLogs v0.1.95 introduces the first game-backed Mechanics Map foundation for the custom UI.

- Adds exact current-build game map textures and world transforms for Cursed Radiant Tomb, Void Towering Ruin, Tina's Mindrealm, and Coral Sea.
- Adds the Season 3 raid's packet-height-selected ring and grid arena layouts without substituting an unrelated older raid texture.
- Adds live packet-observed players, enemies, bosses, markers, and reviewed mechanic signals to the same spatial surface.
- Supports rectangular map presentation, pointer dragging, cursor-centered wheel zoom with no artificial minimum or maximum, and one-click view reset.
- Adds a Developer Mode-only local map preparation action that reads the attached client's exact install and never uploads extracted game assets.
- Keeps unknown builds and unavailable Wasteland Court assets fail-closed rather than presenting unverified map data.
