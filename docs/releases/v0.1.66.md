# rLogs 0.1.66

## Saved loadout directory

- Reads the complete saved in-game loadout directory from one profile sync, so
  players no longer need to equip every loadout just to publish its name.
- Publishes only each loadout's stable project ID, player-written name, and
  class; equipment and module instance maps remain private.
- Keeps stats, equipment, skills, and modules isolated per observed loadout.
  A named loadout without a captured snapshot is clearly marked as awaiting
  observation instead of borrowing details from the active build.
- Adds the public API gateway route required to open previously observed
  loadout snapshots from the profile page.
- Bumps the Blue Protocol: Star Resonance game plug-in to 0.1.4.
