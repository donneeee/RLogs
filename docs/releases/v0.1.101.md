rLogs v0.1.101 completes the hosted automatic-upload recovery path.

- Fixes the Cloudflare verifier container's outbound R2 access so sealed parse chunks can be replayed entirely in hosted infrastructure.
- Preserves the account's public-parse consent while the upload backend synchronizes device identity.
- Distinguishes permanent replay rejections from temporary service failures instead of retrying every error forever.
- Persists deterministic rejection reasons in the local crash-safe queue while retaining the sealed artifact for diagnostics.
- Displays the verifier's concrete reason, such as an incomplete run, and leaves no retry timer scheduled for rejected artifacts.
- Keeps network failures and recoverable server failures on the bounded automatic retry schedule.
