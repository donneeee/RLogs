# rLogs v0.1.69

- Prevents long dungeon sessions from repeatedly rebuilding every historical actor, skill, target, and rDPS view on ordinary overlay refreshes. Exact history is still regenerated whenever the run structure changes and is frozen in full at the authoritative run boundary.
- Keeps Game Time, True Time, retry counts, and view clocks current through lightweight metadata refreshes without rescanning the growing combat-fact ledger.
- Extends durable parser-health diagnostics with exact-versus-lightweight history refresh counts and the current compact-fact count, making long-session pressure visible after a restart.
- Uses the game-defined Monster, Elite, and Boss tiers for encounter classification, including the Stimen Vault exception that promotes Elite floors 3, 8, 13, and so on while retaining native Boss floors 5, 10, 15, and so on.
- Stops the live overlay from redefining `aDPS` and `eDPS` against whichever wall-style timer is selected. `aDPS` stays on the current attempt's paused active-combat clock, while `eDPS` stays on the cumulative encounter-combat clock across retries. Generic DPS/HPS/TPS/rDPS still follow the cycled timer.
