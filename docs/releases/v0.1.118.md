# rLogs v0.1.118

This release expands Mechanics Map into a full-display module on the shared Overlay Canvas.

- `Full map` fills the user's current display at its actual resolution; `Window` restores the previously saved movable and resizable map geometry.
- `Fit` restores the complete map, while `Center` places the packet-observed local player at the center without adding an artificial zoom limit.
- The local game-map texture and all packet-derived entities, markers, and mechanic geometry now use the same aspect-preserving coordinate rectangle. Wide and tall layouts no longer stretch the map underneath otherwise-correct overlays.
- A compact footer exposes the map source, exact local X/Z position, current zoom, and live entity, mechanic, and objective counts.
- All existing reviewed scene packs and locally compiled game-map assets remain supported; unreviewed maps continue to fail closed to the packet radar.

The periodically flashing Combat Meter overlay is tracked as a separate renderer-stability issue and is not claimed as fixed by this map release.
