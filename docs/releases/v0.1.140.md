# rLogs v0.1.140

## Highlights

- Repairs the shared Overlay canvas transition so a stale layout refresh can no longer repaint the dark editor surface after Done or Escape. Edit mode keeps its dark scrim and translucent placement bounds; passive play mode removes editor chrome while preserving each widget's exact saved opacity and geometry.
- Keeps the configurable Scroll Lock canvas toggle separate from the Combat Overlay and restores the shared canvas directly into passive click-through mode without losing its layout.
- Adds a separate desktop recorded-event timeline beneath combat graphs. Exact player skill starts and deaths share each player's graph color and visibility toggle; dense skill uses cluster into readable, truthful summaries, and death markers retain hover and keyboard-accessible cause details.
- Replaces death glyphs with uncircled SVG skull-and-crossbones markers so rendering is consistent and remains visibly matched to each player.
- Prevents unresolved mechanic signals from appearing as reviewed guidance on the real-game-map Mechanics Map.
- Adds the manual ExitLag compatibility baseline: Network Settings exposes the real Npcap Loopback device, preserves an explicit Loopback selection, and explains the possible Legacy-NDIS and monitoring-restart requirement.
- Authorizes rDPS only for receipt-listed same-build bootstrap identities whose protocol semantics reconstruct exactly from the reviewed build-24687926 source. Newer builds and unknown identities remain closed.
- Keeps zero Module Optimizer scores visible and aligns the website's published optimizer engine and reviewed labels with the current desktop implementation.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; ordinary parsing and localization may carry forward across non-seasonal builds, while rDPS remains limited to exact reviewed or receipt-listed same-build identities
- Public report schema: 17; projection revision 10; public reconciliation schema 20; combat timeline schema 6

## Capability status

- Available: Transparent passive shared-canvas rendering, darkened editable canvas, Done/Escape exit, configurable Scroll Lock visibility toggle, exact desktop skill/death event lanes, reviewed real-map Mechanics Map guidance, manual Npcap Loopback capture selection, receipt-bound same-build rDPS authority, and synchronized desktop/site Module Optimizer labels and scoring.
- Locked: Native in-game automarker placement remains disabled until current-build packet proof and a safe end-to-end placement path are complete. rDPS for newer build identities remains disabled until matching formula evidence is reviewed.

## Known limitations

- Automatic late-route discovery for modern ExitLag redirection is not implemented or live-validated yet; ExitLag users may need Packet redirection method > Legacy - NDIS, Npcap Loopback, and Restart monitoring.
- Reports created before combat timeline schema 6 do not contain exact skill-use rows; older death data is shown only as an explicitly labeled one-second bucket.
- Mechanics guidance remains limited to exact reviewed build and scene identities. A real game-map asset is shown only when its reviewed local asset mapping is available.
- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
