rLogs v0.1.73 fixes the Combat Overlay becoming blank or unresponsive during long runs.

- Bounds the live browser payload by sending only overlay-visible player, metric, ability, and timer fields.
- Collapses duplicate target-specific rDPS rows into the same exact provider/recipient/skill total used by the overlay.
- Builds each overlay frame atomically, preserving the last good frame if a live update cannot render.
- Backs off failed live-feed retries instead of repeatedly loading an already struggling host.
- Adds a native renderer heartbeat and automatically reloads a visible overlay after a sustained WebView stall.

Packet capture and combat reduction remain independent from the overlay renderer. Canonical logs and full review history are not trimmed or recalculated by these presentation safeguards.
