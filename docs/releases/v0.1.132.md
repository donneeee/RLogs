# rLogs v0.1.132

## Highlights

- Publishes a server-replayed, canonical clock for reconciled multi-POV rDPS so the website graph, cursor, participant values, and team value use the same run-time denominator.
- Rejects inherited or incomplete POV clocks instead of presenting them as reconciled rDPS evidence.
- Binds desktop history, public parse catalogs, My Parses, and website labels to their exact deployment, client build, and protocol-pack digest; unproven labels fall back to raw IDs.
- Records website parity at `rLogs-app/rlogs-app.github.io` commit `04507d7685bb8af76accb00e1df3caf5332ffed5` (GitHub Checks and Pages deployment passed).

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): 24687926
- Public report schema: 15 (unchanged); public reconciliation schema 18; public catalog schema 7; My Parses schema 2

## Capability status

- Available: Canonical multi-POV replay graphs and cursor-time rDPS for completed schema-18 reconciliations whose server replay is conserved and publishes a complete contiguous rate clock; exact-identity English presentation for build 24687926; raw-ID fallback for legacy or unproven catalog/history labels.
- Locked: Reconciled rDPS timelines without a complete schema-18 replay-authored clock; unreviewed dungeon-mechanic identities; automatic in-game marker transmission and marker preset loading pending packet-identity proof and end-to-end safety validation.

## Known limitations

- Existing schema-17-or-older reconciliations do not acquire the canonical rDPS clock until they are rebuilt by the current verifier.
- Reconciliations that are incomplete, non-conserved, or missing exact replay bounds intentionally show rDPS as unavailable rather than estimating it.
- Localized semantic presentation is currently verified only for the Global 24687926 protocol pack; other or missing identities remain visible with raw numeric IDs.
