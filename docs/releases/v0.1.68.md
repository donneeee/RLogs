- Adds a release-blocking Windows installer smoke test. Each release now remains a draft until the packaged installer completes a silent install into an isolated directory, exposes the expected executable and uninstaller, and reports the tagged file version.
- Publishes the stable installer alias only after that validation succeeds, and records the versioned installer's SHA-256 checksum in these release notes.
