rLogs v0.1.103 makes the packet-backed target frame stable and more informative.

- Shows the resolved packet source under each target debuff, while leaving unknown sources visibly unresolved.
- Counts down packet-supplied debuff durations and removes an expired effect from the live presentation without inventing durations for effects that do not provide one.
- Stops rebuilding the Overlay Canvas when a long-poll timeout returns the same revision, removing the periodic visual flash and preserving countdown continuity.
- Keeps target ownership, status classification, and timing fail-closed behind the current build-versioned packet contract.
