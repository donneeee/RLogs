# rLogs 0.1.63

## Durable parser health and panic supervision

- Persists a privacy-safe, bounded local health history for the newest 32
  parser sessions under `runtime-data/diagnostics/parser-health.v1.json`.
- Records the exact rLogs release, BPSR client build, frame and event progress,
  sealed-run count, recovered auxiliary failures, capture-queue saturation,
  last progress time, and terminal state for each monitored session.
- Marks a previously active session as interrupted on the next application
  launch, retaining its last durable checkpoint instead of losing the evidence
  of an unclean exit.
- Supervises the live capture worker so an unexpected Rust panic becomes a
  visible failed parser state and durable diagnostic entry instead of leaving
  the desktop UI indefinitely blank or falsely monitoring.
- Exposes recent sessions in the normal Settings -> Parser health card; failed
  and interrupted sessions are highlighted and the newest eight can be
  expanded without enabling Developer mode.
- Keeps diagnostics local to the user's PC. No packet contents, character
  identity, or health telemetry is uploaded by this feature.
- Treats parser-health persistence as auxiliary: a disk or JSON failure is
  reported locally but cannot stop packet capture or discard a run.
