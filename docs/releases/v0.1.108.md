rLogs v0.1.108 adds the first packet-backed action module to the screen-sized overlay canvas.

- Adds a movable and resizable Action Cooldowns panel beside the Mechanics Map, player frame, and current-target frame.
- Uses exact `SkillCDInfo` packet observations for cooldown duration, remaining time, charge count, and cooldown type; damage hits are never treated as casts or cooldowns.
- Keeps each exact SkillLevel ID authoritative while using its reviewed base-skill relation only to display the localized action name and packaged game icon.
- Updates countdown masks locally without rebuilding the overlay canvas, avoiding periodic full-window flashes and unnecessary parser work.
- Preserves the panel position and width across launches and clamps restored geometry to the user's current display resolution.
- Advances the bounded overlay-canvas contract to schema 6 so action controls arrive in the same coherent revision as the map, player, and target modules.
