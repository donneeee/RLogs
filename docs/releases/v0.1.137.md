# rLogs v0.1.137

## Highlights

- Adds host-persisted overlay layouts with up to 16 named setups and seven independently movable, resizable, scalable, lockable, and hideable modules.
- Repairs **Open editable overlay** so a missing or hidden Mechanics Map canvas is recreated, shown, initialized from its saved layout, and made interactive through an acknowledged native-window handshake.
- Protects rapid editor and live-canvas changes with revision-aware queued saves, conflict rebasing, backup recovery, and write-through Windows replacement.
- Colors desktop History death skulls with each participant's graph color and adds pointer-hover and keyboard-focus cause-of-death summaries.
- Removes the visible circle around death skulls while retaining an invisible, accessible interaction target.
- Publishes only one versioned Windows installer; the checksum file covers that installer.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): 24687926
- Public report schema: 17; projection revision 9; public reconciliation schema 20; combat timeline schema 5

## Capability status

- Available: Saved overlay setups, editable live overlay layout, trusted real-map Mechanics Map canvas, local automarker previews, participant-colored death markers, and accessible death summaries.
- Locked: Native in-game marker placement remains disabled until current-build packet proof and a safe end-to-end placement path are complete.

## Known limitations

- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
- Mechanics overlays remain limited to reviewed scene-family data available in the installed build.
- Histories recorded without exact death events retain one-second death markers but cannot provide a packet-proven cause summary.
