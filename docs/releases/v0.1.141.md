# rLogs v0.1.141

## Highlights

- Makes shared-canvas play mode transparent by default all the way through each widget: the canvas, widget shells, party rows, objective rows, and alert rows no longer leave dark rectangular backplates over the game.
- Keeps edit mode deliberately distinct with a dark full-screen scrim and translucent widget bounds, then returns to click-through transparent presentation when Done or Escape is used.
- Adds a separate per-widget Background percentage. It defaults to 0% for existing and new layouts, while Widget opacity continues to control the complete widget. This permits an intentional backing without fading text, icons, bars, or map content.
- Resolves exact recorded skill-event icons in the desktop timeline when every event in a cluster has the same known ability; mixed or unresolved clusters retain a neutral truthful marker.
- Keeps partial multi-POV rDPS coverage explicitly incomplete even when observed totals happen to conserve, preventing a partial upload from being presented as authoritative.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; ordinary parsing and localization carry forward across non-seasonal builds, while rDPS remains limited to reviewed identities
- Overlay layout schema: 2, backward-compatible; layouts without Background values migrate to 0%

## Capability status

- Available: Transparent passive shared-canvas widgets, darkened edit canvas, independent per-widget background and whole-widget opacity controls, Done/Escape edit exit, configurable Scroll Lock visibility toggle, resolved recorded skill icons, and fail-closed partial-POV rDPS status.
- Locked: Native in-game automarker placement remains disabled until a current-build outbound placement route and matching visible lifecycle are proven safely.

## Known limitations

- Native-window automation is not available in every development environment, so final game-composited appearance still requires a visual check on the target PC/GPU after installation.
- Automatic late-route discovery for modern ExitLag redirection remains follow-up work; manual Npcap Loopback selection is available.
- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
