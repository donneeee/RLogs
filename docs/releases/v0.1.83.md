rLogs v0.1.83 adds the first packet-backed Mechanics Map milestone and restores live Combat Overlay player rows.

- Fixes dynamic overlay sizing after the protected-frame renderer introduced in v0.1.81.
- Measures each completed replacement frame while it is attached but invisible, so WebView2 reports its real player-row height.
- Keeps the previous good frame visible until the replacement has rendered and been measured.
- Prevents the native overlay window from collapsing to header height and clipping every combatant row.
- Replaces the Mechanics Map navigation mockup with a bounded, live, player-relative radar fed by canonical packet events.
- Shows packet-observed local, party, boss, monster, pet, player, NPC, map-marker, facing, death, cast, mechanic-status, scene, and data-gap state.
- Adds current-build, fail-closed mechanic watches for the audited Cursed Tomb, Void Towering Ruin, Season 3 raid, Coral Sea, Tina, and Wasteland scene families.
- Adds a local-only compiler and fallback theme for the game's official `dungeon_map_bg` texture; extracted game assets are never submitted or bundled.
- Updates the bundled Overlay plug-in to v0.1.4.
