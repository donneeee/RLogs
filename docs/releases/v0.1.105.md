rLogs v0.1.105 makes missing skill casts directly diagnosable and strengthens target-state safety.

- Counts packet-observed local `World.UseSlot` skill requests, successful route decodes, decode failures, and emitted canonical cast starts independently.
- Shows the live cast-observation state and exact counters in Parser Health instead of reducing every failure mode to a zero cast count.
- Persists the counters across normal stops and crashes, with an automatic migration for existing parser-health history.
- Clears the displayed target shield when a replacement shield payload is malformed rather than retaining stale shield state.
- Includes the permanent uploader rejection handling from v0.1.101+, so an invalid incomplete capture stops retrying while valid completed runs continue uploading.
