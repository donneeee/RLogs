# rLogs 0.1.59

## Photo Wall capture guide

- Adds a numbered, live-status guide to BPSR Profile Sync so all four
  packet-defined Photo Wall pages can be captured without guesswork.
- Explains that visiting each wall page loads its occupied tiles and that
  opening an individual photo is optional, but provides the full rendered
  image instead of the exact wall thumbnail.
- Refreshes Photo Wall publication progress while the Profile Sync surface is
  open, without replacing the rest of the page on every status update.
- Clarifies that rLogs only observes exact game replies and never sends Photo
  Wall requests or modifies game data.
