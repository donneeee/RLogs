rLogs v0.1.86 keeps the Combat Overlay visually stable during ordinary live use.

- Stops rebuilding the complete transparent overlay DOM when a long-poll request times out without a new combat revision.
- Coalesces combat bursts to the configured overlay refresh cadence instead of rebuilding once per packet revision.
- Atomically swaps completed overlay frames so WebView2 never exposes an empty compositor frame between updates.
- Debounces transient Windows foreground-process changes before applying the optional hide-when-unfocused policy.
- Keeps real combat, settings, timer, visibility, and renderer-recovery updates live without reducing packet or display accuracy.
- Updates the bundled Combat Overlay plug-in to v0.1.13.
