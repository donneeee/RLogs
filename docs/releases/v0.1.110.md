rLogs v0.1.110 adds passive hold-to-focus behavior to the Overlay Canvas and
prevents Global profile syncs from losing their reviewed server identity.

- Hold controller RB to enlarge the action-cooldown panel with a blue focus
  glow; Right Ctrl is the keyboard fallback.
- Focus observation is passive and never captures, injects, or consumes input.
- The panel scales from the nearest screen edge so focus does not shift the
  rest of the overlay layout.
- Global North America profiles now publish Asteria as their server, while
  Global Europe profiles publish Bahamar.
- Optional profile routing fields are omitted when unresolved instead of being
  published as invalid null values.
