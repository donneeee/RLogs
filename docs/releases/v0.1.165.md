# rLogs v0.1.165

Private developer verification build. This is not a published GitHub release.

## Automarkers

- Adds an explicitly developer-gated Marker 1 placement canary for an exact current dungeon family, scene, map, build, protocol pack, process-owned TCP epoch, saved one-point preset, and fresh packet-observed authority.
- Preserves source-ordered RPC Return and authoritative MarkerAdd confirmation and permits a deliberate re-arm only after fresh authority is observed.
- Retains active interception, rewritten segments, and failed reinjections through ACK, RST, exact bound-process termination, or explicit recovery; it never treats an unconfirmed close as success.
- Maintains WinDivert peer arbitration for the active lifetime and shuts down new receives before byte-identically draining queued packets on safe teardown.
- Reports only bounded `armed` or `not ready` activation states in the developer UI. Public mode remains unavailable.

## Verification boundary

- The canary is restricted to Marker 1 and one active attempt at a time.
- Broader markers, preset sequencing, public activation, and GitHub release publication remain disabled until the live canary is confirmed in game.
