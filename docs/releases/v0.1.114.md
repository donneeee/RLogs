# rLogs v0.1.114

This release adds authoritative encounter timing to the movable dungeon tracker on the native Overlay Canvas.

- The pull clock starts only on the canonical encounter-start boundary.
- It resets for a new pull and freezes on a packet-proven wipe, clear, or end boundary.
- A packet-proven retry count appears beside the fixed-width, tabular timer.
- The timer advances locally between packet updates without rebuilding the overlay DOM.
- The Mechanics Map contract is versioned to schema 11 so incompatible payloads fail closed.

The v0.1.113 packet-backed player status HUD and v0.1.112 server-identity fix remain included.
