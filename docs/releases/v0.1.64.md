# rLogs 0.1.64

## Pull timing and dungeon boss presentation

- Adds an `Attempt` timer to the Combat Overlay timer cycle. It measures only
  the current pull, clears during retry recovery, and starts from zero on the
  next hostile event without resetting encounter or run timing.
- Recalculates visible DPS, eDPS, aDPS, HPS, TPS, and rDPS against the selected
  Attempt timer just like the existing Encounter, Game, True, and Run clocks.
- Uses the same resolved boss entities that power live boss HP rows to display
  `Boss: <name>` in the scene header for every dungeon.
- Keeps the localized dungeon/scene name when no currently damaged boss is
  present, including during mobbing and transition phases.
- Enables the reviewed Mistveil master run rule so its objective gate and
  monster identity produce a proper boss phase instead of the generic
  master-dungeon fallback.
- Bumps Combat Meter to 0.1.3, Combat Overlay to 0.1.7, and the BPSR game
  plug-in to 0.1.3.
