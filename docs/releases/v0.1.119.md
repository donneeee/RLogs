# rLogs v0.1.119

- Expands the Overlay Canvas from six encounter maps to every current-build
  in-game map family joined to an active scene: cities, open world, dungeons,
  raids, towers, world-boss arenas, guild activities, and housing.
- Keeps all game textures local. The installer contains only the strict map
  compiler and its build-locked manifest; maps are extracted from the user's
  own installed client and are never uploaded.
- Adds a complete scene-map inventory and visual-review path backed by the
  exact build-24687926 SceneTable and SceneResourceTable hashes.
- Speeds up full map preparation by reading the 1.2 GB address catalog and
  package index once per batch instead of once for every map.
- Retains unreferenced and alternate-floor textures as audited candidates
  instead of attaching them to the wrong scene or floor.
