# rLogs 0.1.62

## Parser resilience and correct run state

- Keeps process-owned packet capture and sealed `.rlog` recording alive when
  an auxiliary live overlay, history, identity, or presentation projection
  fails. Recoverable failures no longer blank the parser or discard later
  attempts.
- Adds privacy-safe Parser health diagnostics to Core settings, including
  capture and decode progress, sealed-run count, recovered error count, the
  latest bounded error, and capture-queue saturation.
- Preserves character names, UIDs, class data, and loadout identity across a
  forced Reset while still clearing combat totals and invalidating the active
  attempt for submission.
- Fixes Game time boundaries when a mobbing-complete packet carries both an
  unrecognized nested objective ID and the configured stable objective-map
  key. The mobbing clock now stops at the verified clear boundary and resumes
  only for the boss segment.
- Keeps a sealed run on disk even if its optional history/submission
  postprocessor becomes unavailable, while reporting the condition through
  Parser health instead of stopping capture.
