# rLogs v0.1.117

This release adds packet-backed class-resource gauges to the shared Overlay Canvas.

- The local-player module now displays the reviewed current/max resource pairs for Stormblade, Frost Mage, Twin Striker, Wind Knight, and Verdant Oracle.
- Resource arrays are accepted only when their packet-provided ID and value lengths match; incomplete or unknown data stays hidden instead of being guessed.
- Only reviewed HUD resource IDs are retained, keeping the projection bounded and preventing unrelated resource traffic from displacing class gauges.
- Holding controller RB, or Right Ctrl as the keyboard fallback, now applies the blue focus enlargement to the local-player module as well as action controls.
- The native snapshot and browser adapter schema advance to version 12 with matching Rust and TypeScript coverage.

This is an additive Overlay Canvas slice. It does not copy assets or source from Resonance Logs CN; its current mappings were independently cross-checked against the latest audited upstream behavior. Game-extracted gauge art and Verdant Oracle's bloom-rotation treatment remain follow-up work.
