rLogs v0.1.76 fixes intermittent Combat Overlay focus theft introduced by automatic recovery.

- Stops treating an idle combat feed as a frozen overlay renderer. Remaining out of combat no longer causes WebView2 to reload every 30 seconds.
- Reveals the Windows overlay with the native non-activating window contract (`WS_EX_NOACTIVATE` and `SW_SHOWNOACTIVATE`) on every startup, combat wake-up, focus-policy restore, and recovery path.
- Hides a genuinely stalled overlay before reloading its renderer, then restores it without activating it.
- Adds a native Windows regression test proving that the overlay reveal becomes visible without becoming the foreground window.
