rLogs v0.1.75 fixes long-session Combat Overlay recovery and improves the evidence recorded for new parses.

- Keeps the Combat Overlay non-activating during initial display, automatic combat wake-up, focus-policy restoration, and renderer recovery, so it cannot take keyboard or controller focus from the game.
- Adds a bounded live-feed request and distinguishes a responsive renderer from a stalled parser feed in Parser health; a genuinely stalled visible overlay can recover without restarting rLogs.
- Records exact local-player cast events when an authenticated character profile is available even if the scene-local self-entity packet was missed. Hits are still never guessed to be casts.
- Uses an exact, unique dungeon-ID match to replace a stale town scene when a load-screen world-change packet was missed, preventing new dungeon submissions from being labeled Asterleeds.

Existing immutable reports keep the evidence they were originally submitted with. The cast and scene corrections apply to newly captured parses made with this release.
