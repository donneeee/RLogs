# rLogs v0.1.142

## Highlights

- Removes the Mechanics Map canvas's redundant 94%-opaque full-widget paint so passive gameplay shows only the real map and mechanic content over the game.
- Hides the map's waiting or unavailable notice after Done or Escape; editor-only status chrome no longer remains over gameplay.
- Keeps the shared Overlay canvas dark and its widget bounds translucent only while editing. Passive widget backplates remain controlled exclusively by each widget's Background percentage, which defaults to 0%.
- Promotes 16 exact current-build SkillTable action names through the reviewed desktop localization catalogs, improving website observed-action coverage from 232/262 to 248/262 without guessing unresolved identities.
- Maps exact timeline skill icons referenced by `/game-assets/...` to matching trusted site-owned assets, while rejecting mismatched or unsafe paths.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; ordinary parsing and localization carry forward across non-seasonal builds, while rDPS remains limited to reviewed identities
- Public report schema: 17; projection revision 10; public reconciliation schema 20; combat timeline schema 6
- Overlay layout schema: 2, backward-compatible; layouts without Background values migrate to 0%

## Capability status

- Available: Transparent passive shared-canvas widgets, real-map rendering without an extra opaque canvas fill, editor-only map notices, independent Background and Widget opacity controls, Done/Escape edit exit, configurable Scroll Lock visibility toggle, and expanded exact current-build action localization.
- Locked: Native in-game automarker placement remains disabled until a current-build outbound placement route and matching visible lifecycle are proven safely.

## Known limitations

- Existing public reports are not automatically upgraded to timeline schema 6; retained reports require a rollback-safe reprojection before exact skill lanes and death-cause evidence appear for those older submissions.
- Automatic late-route discovery for modern ExitLag redirection remains follow-up work; manual Npcap Loopback selection is available.
- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
