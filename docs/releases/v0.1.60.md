# rLogs 0.1.60

## Safer unfinished-feature access

- Adds a global Developer mode switch under Settings that defaults off for
  both new installs and existing settings files.
- Keeps Custom Triggers and Event Inspector, the future modular Overlay
  workspace, and Session Tools out of the normal workspace and settings
  catalogs until Developer mode is enabled.
- Blocks direct plug-in and Event Inspector entry points while Developer mode
  is off, instead of allowing half-implemented surfaces to open accidentally.
- Adds a reliable close control to Event Inspector and closes any existing
  inspector window when Developer mode is turned off.
- Centralizes the developer-only feature list so a completed feature can be
  promoted by removing its single registry entry, with regression coverage
  for both enabling and disabling the mode.
