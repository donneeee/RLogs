# rLogs v0.1.116

This release fixes completed dungeon logs that remained open after returning to town.

- A dungeon opened before its first usable world packet now binds that first scene as its active dungeon scene.
- The following authoritative world transition back to town seals the canonical `.rlog` immediately, after the reward and dungeon-summary flow.
- Later town packets and delayed completion updates can no longer leak into that run.
- The live overlay/history projector uses the same late-scene binding, so it freezes at the same boundary as persistence.

The v0.1.115 packet-backed mechanic alerts and earlier Overlay Canvas work remain included.
