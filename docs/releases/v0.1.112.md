# rLogs v0.1.112

This release fixes Global-region identity at its source and completes the current-build dungeon objective overlay work.

- Asteria is now consistently published as North America, while Bahamar is consistently published as Europe. Global remains the deployment identity.
- Packet detection, desktop parse/profile projection, and Cloudflare profile ingestion now share the same canonical mapping.
- Less-specific fallback snapshots can no longer overwrite a previously established regional server identity.
- The current game build now ships a verified dungeon-objective catalog with localized names and required totals.
- The objective overlay shows named objectives, current/required progress, completion state, and compact progress bars.
- CI verifies that the bundled objective catalog still matches its reviewed current-build source data.
