# rLogs v0.1.148

## Highlights

- Adds 1-second, 5-second, 10-second, and whole-run eDPS/aDPS pairs to the Combat History damage-chart inspector for every visible player, plus a visible-player total.
- Uses the canonical recorded microsecond duration for fractional run endings, keeping graph samples, event lanes, the cursor, and terminal markers aligned.
- Keeps incomplete history honest: time-local eDPS/aDPS remains unavailable when the reducer did not publish a complete validated rate clock; wall time is never substituted.
- Prevents unsupported builds from inferring a Battle Imagine item, icon, tier, rarity, or maximum tier from a current-build ability mapping. Stable names carry forward only from an item ID that was actually observed.
- Keeps Hide, Lock, Done, and Escape in the independently localized Overlay Canvas control path rather than making a specific overlay module own the canvas.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; ordinary parsing and stable ID-backed localization carry forward, while inferred Imagine presentation, mechanics, and rDPS identities remain exact-authority gated
- Public report schema: 17; projection revision 12; public reconciliation schema 21; combat timeline schema 8
- Combat History schema: 1, backward-compatible; exact cursor variants require a complete reducer-authored rate clock
- Overlay layout schema: 2, backward-compatible

## Capability status

- Available: Exact 1s/5s/10s/run eDPS and aDPS inspection in Combat History, visible-player totals, canonical fractional-run timing, participant-controlled graph/event visibility, stable observed-item Imagine labels across compatible builds, and independent canvas-level Hide/Lock/Done controls.
- Locked: Native in-game automarker placement remains disabled until a current-build outbound placement route and matching visible lifecycle are proven safely. Multi-POV death merging remains disabled until each secondary death is derived from a verified sealed artifact with its own server-time evidence and collision-safe identity mapping. Historical projection publication remains paused until a deployed isolated staging canary passes.

## Known limitations

- Combat History records without a complete reducer-authored rate clock cannot expose time-local eDPS/aDPS variants. The app displays them as unavailable instead of estimating them from wall time.
- Timeline playback remains website-only; the desktop app provides inspection and event navigation without playback.
- Secondary-POV death rows are not copied from public/client timeline JSON. The public death schema does not yet retain each death event's own server time, so safely aligned multi-POV death merging requires a later sealed-replay schema slice.
- The local forward/rollback rehearsal validates the transaction layer but does not replace the final hosted-verifier staging canary, so production historical reprojection remains paused.
- Automatic late-route discovery for modern ExitLag redirection remains follow-up work; manual Npcap Loopback selection remains available.
- Native in-game automarker transmission remains unavailable; saved scene-family marker presets and preview behavior do not send placement packets.
