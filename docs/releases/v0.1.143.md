# rLogs v0.1.143

## Highlights

- Adds separate hostile cast lanes to the desktop and website timelines, showing exact observed cast starts before the player skill/death lanes without inferring boss identities.
- Keeps hostile cast lanes visible when player graph lines are toggled off, and uses trusted localized action names and icons where available.
- Publishes timeline schema 7 with a bounded reducer-authored hostile-source roster, exact evidence, target-aware single-POV deduplication, and canonical multi-POV clock alignment.
- Localizes desktop death-cause summaries and every fallback label through the UI catalog.
- Locks the Overlay canvas visual contract with regression coverage: a dark translucent edit canvas, no passive canvas/backplates, and only user-configured widget background opacity during play.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; ordinary parsing, localization, and non-seasonal build compatibility carry forward, while rDPS remains limited to reviewed identities
- Public report schema: 17; projection revision 11; public reconciliation schema 20; combat timeline schema 7
- Overlay layout schema: 2, backward-compatible; layouts without Background values migrate to 0%

## Capability status

- Available: Exact hostile cast and player skill/death timeline lanes, trusted skill presentation, synced-POV cast alignment, transparent passive shared-canvas widgets, editor-only dark canvas and widget bounds, Done/Escape edit exit, and configurable Scroll Lock visibility.
- Locked: Native in-game automarker placement remains disabled until a current-build outbound placement route and matching visible lifecycle are proven safely. Historical projection publication remains paused until the inverse rollback transaction is implemented and tested.

## Known limitations

- Existing public reports are not automatically upgraded to timeline schema 7. Bounded audit-only dry runs are safe while publication is paused, but older submissions will not gain exact skill, death-cause, or hostile-cast lanes until rollback-safe reprojection is enabled.
- Automatic late-route discovery for modern ExitLag redirection remains follow-up work; manual Npcap Loopback selection is available.
- Hostile actors are intentionally labeled by trusted presentation data or raw actor ID; rLogs does not guess boss names.
