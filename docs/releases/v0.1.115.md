# rLogs v0.1.115

This release adds a movable mechanic-alert module to the native Overlay Canvas.

- Only signals from reviewed, current-build encounter packs are displayed.
- Packet-duration status effects count down locally without requiring UI rebuilds.
- Reviewed cast signals are labeled `OBSERVED`; rLogs does not misrepresent the host's stale-data lifetime as an authoritative cast timer.
- Alert position and width persist with the rest of the canvas layout.
- Expired timed effects disappear locally while the packet feed catches up.

The v0.1.114 packet-driven dungeon pull timer and source-side server identity fix remain included.
