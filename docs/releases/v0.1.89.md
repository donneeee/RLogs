rLogs v0.1.89 makes module recommendations easier to compare and strengthens hosted profile ingestion.

- Shows each recommended module loadout's finalized score on the same compact row as its combined Link totals.
- Shows the currently equipped score after comparison, including a separate priority score only when the selected preferences change ranking.
- Keeps threshold power and other internal scoring components out of the compact presentation.
- Preserves remote participant identity with stable opaque character keys instead of publishing another player's raw UID.
- Automatically refreshes the observed-player directory whenever verified public parse catalogs are rebuilt.
- Includes the generated observed-player directory in guarded Cloudflare state imports.
