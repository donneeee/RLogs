# rLogs v0.1.150

## Highlights

- Gives automarker presets an explicit local Load action that restores the selected setup's name and exact XYZ points without opening the Mechanics Map or transmitting game traffic.
- Separates the unverified native action as a clearly disabled Place in game control; Save, Save As, Load, and scene-family isolation remain usable independently of DPS and the overlay canvas.
- Removes expired mechanic geometry from the real game map on time even when no new packet revision arrives, while keeping removal-driven signals visible until the game removes them.
- Makes scaled overlay dragging, resizing, saving, and reloading share the same authority bounds, eliminating edge snapping and preserving natural panel height while layout data is delayed or unavailable.
- Adds a five-artifact hosted reconciliation proof that retains one canonical combat spine, prevents secondary-POV damage duplication, and verifies exact source-set and rDPS conservation behavior.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926; preset families and stable labels carry forward, while mechanics, native placement, and rDPS semantics remain exact-authority gated
- Public report schema: 17; projection revision 12; public reconciliation schema 21; combat timeline schema 8
- Overlay layout schema: 2, backward-compatible; scaled geometry uses the existing authority clamps

## Capability status

- Available: Local automarker Save, Save As, and explicit Load by reviewed activity family; quiet-period mechanic expiry; scale-consistent overlay editing; and synthetic five-POV reconciliation conservation coverage.
- Locked: Native Place in game remains disabled until a current-build outbound placement route and matching visible lifecycle are proven safely. Multi-POV death merging remains disabled until each secondary death is derived from a verified sealed artifact with its own server-time evidence and collision-safe identity mapping. Historical projection publication remains paused until a deployed isolated staging canary passes.

## Known limitations

- Load restores a saved setup locally; it does not place party-visible in-game waymarks. Place in game remains disabled and does not send packets.
- The Mech Facility M1 capture is useful negative evidence but did not reveal a decoded outbound placement request, so another placing-client capture is still required for native automarkers.
- Five-POV reconciliation is now covered by sealed synthetic artifacts, but production raid validation still requires a real same-instance 5+ POV corpus.
- ExitLag compatibility still requires native validation with ExitLag Legacy-NDIS and Npcap installed; the passive capture path cannot expose traffic that Npcap itself does not provide.
