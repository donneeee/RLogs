# rLogs v0.1.139

## Highlights

- Keeps the shared Overlay canvas visible when Escape or Done exits editing: widgets stay mounted while editor controls disappear and the native window returns to passive click-through mode. Show, Edit, and Hide are separate actions, and the enabled state now survives application relaunches.
- Adds a configurable global shared-overlay hotkey, defaulting to Scroll Lock. It hides or restores the seven-widget canvas in passive click-through mode without toggling the separate Combat Overlay.
- Repairs Combat Overlay preview/live parity for saved background color, opacity, custom backgrounds, layout, and dummy-mode styling.
- Eliminates the periodic Combat Overlay flash caused by an unregistered heartbeat permission and rejects stale in-flight settings while a hidden overlay is being restored.
- Restores Mechanics Map launch permissions and route handling. Maps render only reviewed real game-map assets, and mechanic annotations appear only for exact triggered mechanics.
- Carries the current reviewed build pack and localization forward across ordinary game builds. Seasonal updates still require an explicit review and pack refresh.
- Carries trusted Module Optimizer module and effect labels across ordinary source-build identities by stable ID while optimizer mechanics and scoring remain exact-authority gated.
- Publishes exact packet-observed skill uses on the reconciled run clock for the website's synchronized DPS graph and event-lane timeline.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): reviewed pack 24687926, carried forward to ordinary non-seasonal client builds
- Public report schema: 17; projection revision 10; public reconciliation schema 20; combat timeline schema 6

## Capability status

- Available: Saved shared-canvas layouts, a configurable Scroll Lock visibility toggle, passive click-through display, editable layout mode, trusted real-map Mechanics Map rendering, local automarker previews, exact skill-use publication, and build-aware localization carry-forward.
- Locked: Native in-game marker placement remains disabled until current-build packet proof and a safe end-to-end placement path are complete.

## Known limitations

- Explicit Hide disables and hides the shared canvas until Show or Edit is chosen again; Escape or Done leaves it enabled and visible in passive mode.
- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
- Mechanics and combat interpretation remain limited to explicitly supported runtime identities even when trusted catalog labels can be carried forward.
- Reports created before combat timeline schema 6 do not contain exact skill-use rows.
