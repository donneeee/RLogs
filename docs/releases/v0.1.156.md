# rLogs v0.1.156

## Highlights

- Publishes a decoded world change to the live combat overlay immediately, so scene labels do not wait for unrelated combat or actor traffic.
- Treats the read-only native scene observer as a startup fallback only; newer packet-backed scene evidence now wins across the combat overlay, Automarkers, and Mechanics Map.
- Clears stale Automarker context when the player enters a packet-observed scene that has no reviewed Automarker family.
- Clears native scene fallbacks at capture-session reset so a previous dungeon cannot briefly reappear in a new session.
- Keeps ordinary world and server-time chatter off the immediate repaint path to avoid reintroducing overlay refresh flashes.
- Includes the scene/line decoding and per-POV skill-timeline coverage shipped in the private 0.1.155 validation build.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Current observed game build: 25247556, using the reviewed 24687926 compatibility epoch for stable packet and display identities
- Public report schema: 17; projection revision 13; public reconciliation schema 22; combat timeline schema 9

## Capability status

- Available: packet-authoritative scene presentation, exact local outbound skill rows with truthful per-participant coverage, multi-adapter capture continuity, opt-in ExitLag loopback capture, local Automarker preset Save/Save As/Load, and the unified overlay canvas.
- Conservative: native scene observation is presentation-only and yields to canonical packet evidence; it does not create run, upload, map-mechanic, or Automarker-placement authority.
- Locked: native party-visible Automarker placement remains disabled until its game-owned dispatch path and server-observed lifecycle are fully verified for the current build.
- Paused: historical public-report projection backfill remains disabled pending an explicit operator rollout and deployed forward/rollback canary.

## Known limitations

- A scene can remain unresolved when rLogs starts mid-session and no transition-bearing packet has appeared yet. Steady-state combat/entity traffic does not contain enough evidence to reconstruct it safely.
- Sea-Ringed Reef Automarker presets currently follow the reviewed master scene identity `6565`. If a live transition proves that M1 emits `6561`, that family mapping must be reviewed before presets are enabled for it.
- Other players' complete skill timelines require their synchronized POV logs.
