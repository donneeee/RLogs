# rLogs 0.1.65

## Live Game-time phase pause

- Publishes the reviewed Game-time clock while a dungeon run is still active,
  instead of waiting until the run is complete.
- Pauses Game time immediately when the packet-owned mobbing objective closes
  the mobbing segment.
- Keeps Game time paused through the transition and resumes it only when boss
  engagement opens the reviewed boss segment.
- Prevents the desktop overlay from substituting the continuously increasing
  Run timer when the reviewed Game-time clock is unavailable.
- Leaves Attempt, Encounter, True, and Run timer behavior unchanged.
- Bumps Combat Meter to 0.1.4.
