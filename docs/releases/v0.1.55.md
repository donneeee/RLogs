rLogs v0.1.55

- Adds a deterministic Rust plug-in fixture harness that verifies manifest
  identity, event subscriptions, expected output schemas, and repeatable output
  before a community analyzer is treated as compatible.
- Includes a sealed reference fixture and runnable SDK example so plug-in
  authors can test the same event stream through fresh instances and catch
  hidden state or nondeterministic behavior.
- Keeps fixture execution bounded and fail-closed: empty suites, manifest drift,
  unexpected output schemas, and mismatched fixture identities are rejected.
