# rLogs v0.1.135

## Highlights

- Retains packet-proven death replay evidence in private combat history, including the terminal hit and a bounded two-second recent-damage window.
- Publishes exact death markers and packet-proven cause summaries for new hosted replays without exposing private entity identities.
- Adds the public timeline schema used by the website's player-colored skull markers and hover, touch, and keyboard-accessible death summaries.
- Publishes exact difficulty evidence for profile parse involvement instead of fabricating a tier when authority is unavailable.
- Hardens hosted verification so report, projection, reconciliation, and timeline schema versions are accepted only in reviewed combinations.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): 24687926
- Public report schema: 16; projection revision 8; public reconciliation schema 19; combat timeline schema 4

## Capability status

- Available: Packet-proven private death-event retention; new-report public death markers and two-second cause summaries; exact difficulty publication; website timeline playback, time-sliced DPS inspection, player-colored death skulls, and accessible death details (website commit `26279a1`).
- Locked: Historical report backfill to timeline schema 4 remains disabled until the backfill producer and target are upgraded and verified together. Native in-game marker placement remains locked behind current-build packet proof and a safe end-to-end placement path.

## Known limitations

- The death-summary interface is currently website-only; this installer does not add a desktop death-tooltip view.
- Existing schema-3 timelines remain unchanged and explicitly report that exact death-cause evidence is unavailable.
- Death causes use authoritative numeric actor and ability identifiers when no exact-build public presentation is available; they never borrow or invent names.
- Direct-source naming and complete boss-skill localization require additional event-time identity retention and a reviewed exact-build monster-skill catalog.
