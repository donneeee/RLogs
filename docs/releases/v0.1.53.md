rLogs v0.1.53

- Makes desktop account connection changes transactional across Windows
  Credential Manager and the local endpoint settings file.
- Restores the previous device credential if a connect or disconnect settings
  write fails, preventing a storage error from silently breaking a working
  website connection.
- Writes endpoint settings through a synced partial file and atomic replacement
  so an interrupted update cannot leave truncated account configuration.
- Retains the v0.1.52 combat-overlay geometry fix: the designer and live overlay
  share the same fixed-width timer control.
