rLogs v0.1.97 is a startup reliability hotfix for the Windows desktop app.

- Fixes the immediate `0xc00000fd` stack-overflow crash that could make a successful installation appear to do nothing.
- Reserves an 8 MiB Windows main-thread stack for the desktop host's bounded startup initialization; pages remain demand-committed rather than consuming 8 MiB up front.
- Strengthens release validation by launching the installed executable and requiring a responsive rLogs window instead of checking only its file header and version.
- Includes the completed game-backed Season 3 raid mechanic geometry from the current Mechanics Map slice.
