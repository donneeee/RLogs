# rLogs v0.1.120

## Run settlement and target-frame corrections

- Freeze the visible run result at terminal boss death while retaining reward and dungeon-summary packets in the same capture.
- Seal completed dungeon captures when the client actually departs the instance, preventing later town traffic from extending the run.
- Reset the live combat overlay as the client returns to town so the completed party and timer do not linger over the overworld.
- Limit the movable current-target panel to debuffs applied by the local player.
