# rLogs v0.1.138

## Highlights

- Adds host-persisted overlay layouts with up to 16 named setups and seven independently movable, resizable, scalable, lockable, and hideable modules.
- Repairs **Open editable overlay** so a missing or hidden Mechanics Map canvas is recreated, initialized from its saved layout, and made interactive through an acknowledged native-window handshake.
- Stops unchanged combat-overlay polls from rebuilding the live canvas, eliminating periodic refresh flashes while preserving updates for visible state changes.
- Removes the large translucent live-overlay rectangle while retaining compact row backplates and text shadows for readability.
- Resolves known scene, monster, action, status, weapon, class, and specialization names and icons by trusted catalog ID across source builds. Unknown IDs remain unresolved, while combat semantics and mechanics remain exact-authority-only.
- Colors desktop History death skulls with each participant's graph color, removes the visible circle, and adds pointer-hover and keyboard-focus cause-of-death summaries.
- Publishes only one versioned Windows installer; the checksum file covers that installer.

## Compatibility

- Platform: Windows x64
- Game deployment: Global
- Game build(s): 24687926
- Public report schema: 17; projection revision 9; public reconciliation schema 20; combat timeline schema 5

## Capability status

- Available: Saved overlay setups, editable live overlay layout, trusted real-map Mechanics Map canvas, local automarker previews, cross-build catalog labels, participant-colored death markers, and accessible death summaries.
- Locked: Native in-game marker placement remains disabled until current-build packet proof and a safe end-to-end placement path are complete.

## Known limitations

- Overlay monitor selection and per-monitor DPI-aware setup assignment remain follow-up work.
- Mechanics and combat interpretation remain limited to explicitly supported runtime identities even when trusted catalog labels can be displayed for other builds.
- Histories recorded without exact death events retain one-second death markers but cannot provide a packet-proven cause summary.
