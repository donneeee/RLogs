rLogs v0.1.111 adds a packet-backed dungeon objective module to the shared
Overlay Canvas.

- Dungeon identity, difficulty, flow phase, objective IDs, values, and
  completion state come from canonical packet events.
- The module can be moved and resized independently and its geometry persists.
- Missing current-build catalog data fails closed: unresolved objectives use
  their packet ID and exact value without guessed labels or target thresholds.
- Dungeon exit and scene changes clear stale objective state.
- The Overlay Canvas contract is now schema version 8.
