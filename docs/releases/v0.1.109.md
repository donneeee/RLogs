rLogs v0.1.109 adds packet-rostered party frames to the shared overlay canvas.

- Adds a movable and resizable Party panel beside the Mechanics Map, player, target, and action-cooldown modules.
- Shows joined party actors with packet-observed names, HP, shields, defeated state, and explicit stale state.
- Requires authoritative party membership and a matching live actor; combat rows and profile snapshots are never substituted for an absent teammate.
- Bounds the live contract to 39 remote party frames and validates that limit at the UI boundary.
- Preserves party-panel position and width across launches while clamping restored geometry to the current display resolution.
- Advances the unified overlay-canvas snapshot to schema 7 so every module renders one coherent live revision.
