rLogs v0.1.54

- Makes the Combat Overlay designer use the current live overlay snapshot by
  default, so its scene, timers, roster, and waiting state match the native
  overlay instead of always showing unrelated sample combat.
- Adds an explicit Example combat preview mode for arranging populated player
  rows when no encounter is active, plus a refresh control for live data.
- Routes designer snapshots through the same actor projection and timer-pause
  policy as the native overlay.
- Enforces one fixed-width Cycle timer control in saved settings, inline layout,
  and CSS so changing timer names or values cannot shift adjacent controls.
- Updates the Combat Overlay plug-in version to v0.1.5.
