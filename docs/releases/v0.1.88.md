rLogs v0.1.88 preserves and recovers queued parses across app-folder or workspace moves.

- Rebinds a retained submission draft to its relocated sealed `.rlog` artifact when the queue and artifact directories move together.
- Requires the relocated file to match both its recorded byte length and full SHA-256 digest before making it upload-eligible or updating the persisted queue path.
- Rejects altered or incorrectly named artifacts and leaves an auditable queue issue instead of submitting uncertain evidence.
- Keeps unavailable hosted parse writes fail-closed while retaining valid local drafts for a later automatic retry.
- Adds revision-stamped Cloudflare health checks, guarded deployment automation, and production smoke tests for profiles, parses, Discord authentication, CORS, and protected writes.
- Makes website reads retry bounded transient network, 408, 429, 5xx, and Cloudflare 530 failures without retrying writes or deleting a valid signed-in session.
