rLogs v0.1.94 corrects live damage-rate timing across combat downtime.

- Freezes aDPS while the party is inactive and resumes it in a new active window instead of retroactively counting the idle gap.
- Keeps eDPS on the shared encounter-combat clock, which also remains frozen outside combat.
- Applies the one-second startup floor consistently so the first damage event produces a useful, finite aDPS value.
- Preserves the existing mobbing checkpoint, boss transition, retry rollback, and terminal boss clock behavior.
- Includes the compact current/recommended module score summaries introduced in v0.1.90 and the compact home ranking layout already deployed to the website.
