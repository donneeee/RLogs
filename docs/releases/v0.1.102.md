rLogs v0.1.102 adds the first packet-backed target frame to the shared Overlay Canvas.

- Decodes the current build's exact selected-target entity attribute instead of guessing a target from recent damage.
- Shows the selected target's observed current and maximum HP, percentage bar, death state, and stale-state warning.
- Shows exact-ID effects only when the reviewed game presentation classifies them as debuffs, including localized names, game icons, and stack counts.
- Clears target state on the packet's target-clear value, actor despawn, and scene transition.
- Adds the target frame to the same screen-sized native canvas as Mechanics Map, with independently saved position and width.
- Keeps missing HP and unclassified effects unavailable rather than converting absent packet evidence into zero or a debuff.
