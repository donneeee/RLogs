# rLogs v0.1.131

- Retries automatic local map extraction when updated game package files are temporarily unavailable or still settling.
- Uses bounded backoff so a patch cannot cause a tight extraction loop or overload the parser.
- Stops retrying when live capture ends and switches immediately when a newer packet-observed build replaces the current build.
- Keeps extracted game assets local-only and keeps unreviewed mechanic identities disabled.
