rLogs v0.1.79 is a corrective release for the new raid-completion path in v0.1.78.

- Preserves monotonic event timestamps when a packet-proven final boss objective is sealed at the following run exit or scene departure.
- Keeps post-boss packets in their original order while still ending the boss encounter at the exact completed-objective timestamp.
- Prevents server replay from rejecting a completed Nightmare raid because its inferred completion boundary moved backward in time.
- Updates the Blue Protocol: Star Resonance game plug-in to v0.1.11.
