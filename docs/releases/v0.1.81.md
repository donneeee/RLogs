rLogs v0.1.81 restores packet-observed class-skill cast counts.

- Records exact local skill starts from `World.UseSlot` even when the request legitimately omits its optional encrypted action-speed snapshot.
- Continues attaching authenticated attack, cast, and charge-speed timing metadata when the client supplies it.
- Keeps present-but-invalid action-speed envelopes fail-closed instead of silently accepting corrupted metadata.
- Allows new parses to show real per-skill cast totals on the desktop history and website rather than reporting every class skill as unobserved.
- Keeps older immutable reports truthful: parses captured before this fix cannot reconstruct the rejected raw requests and remain labeled as casts not observed.
- Updates the Blue Protocol: Star Resonance game plug-in to v0.1.13.
