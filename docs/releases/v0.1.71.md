# rLogs v0.1.71

- Detects the Global standalone, Steam, Epic, SEA, Asia, Taiwan, and CN BPSR client executable families used by current community parsers.
- Resolves the live server region from the early `NotifyEnterWorld.scene_ip` packet and carries that evidence into subsequent live events and run headers.
- Keeps unknown server hosts unresolved and disables automatic log submission when a non-Steam launcher does not provide a trusted exact-build receipt.
- Preserves exact Steam manifest selection while allowing other supported clients to start a clearly marked provisional local capture.
