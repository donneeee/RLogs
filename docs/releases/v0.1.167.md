# rLogs v0.1.167

Private Automarkers canary diagnostics build.

## Automarkers

- Reports the active placement lifecycle from the native rewrite worker rather than retained parser readiness.
- Separately reports carrier interception, modified request dispatch, transport acknowledgement, RPC return, and authoritative marker confirmation.
- Declares success only after all three confirmations arrive and the transport rewrite obligation is retired.
- Retains a bounded terminal result across scene and connection cleanup.
- Allows sequential re-arming only after the previous attempt is terminal and a strictly newer game-generated marker carrier is observed.
- Keeps lifecycle diagnostics sanitized: no process, socket, session, call, sequence, packet, or coordinate identity is exposed.

This build does not add a no-menu native trigger. The live canary still requires a fresh game-generated Marker 1 request.
