# rLogs v0.1.162

## Highlights

- Replaces the withdrawn private 0.1.161 Automarker readiness build.
- Starts the passive Automarker connection observer before capture ingress and scene discovery, so the dungeon connection SYN is not missed.
- Treats an observed game-process SYN as a short-lived private candidate until the parser independently confirms the exact BPSR socket and marker carrier.
- Rejects unrelated game connections without falsely reporting native readiness, then re-arms observation on the next connection epoch.

## Capability status

- Available: early read-only Automarker connection observation, exact parser/socket correlation, localized sanitized readiness stages, local preset Save/Save As/Load, packet-only identity and scene recovery, combat history timelines, and the unified overlay canvas.
- Conservative: readiness remains exact-session, process, tuple, connection-epoch, build, pack, scene, actor, carrier, and freshness scoped; all private candidates are bounded and cleared on discontinuity.

## Known limitations

- rLogs must be launched as administrator before the game so it can provision the reviewed passive driver and observe new game connections.
- This private test build observes and displays readiness evidence but does not place markers automatically.
- Multi-marker activation remains fail-closed while the one-marker native dispatch path is completed first.
