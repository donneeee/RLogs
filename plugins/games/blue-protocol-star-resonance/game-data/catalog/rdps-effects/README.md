# rDPS effect review catalog

This catalog is the human-readable review layer for status effects that may
change another actor's damage contribution. Numeric effect IDs remain the
identity; localized names are evidence, not runtime keys.

Each reviewed record contains the exact rule emitted into the compact runtime
classification table plus the current-build evidence that justified the
review. A candidate is never used for attribution. It can become an enabled
rule only after capture evidence proves its provider, target scope, magnitude,
and stacking behavior.

Formula closure proceeds one effect at a time. Before a candidate can use
cohort-scale counterfactual replay, a versioned receipt must join the exact
provider and lifecycle instance to its recipient or target, prove the
event-time attribute or mitigation transition on uncontaminated packet rows,
and then join affected damage actions to their independent source and target
endpoints. A matching aggregate formula is not a substitute for an observed
application/removal transition. Cohort enumeration remains discovery evidence
until this single-effect chain, operation order, integer rounding, stacking,
and conservation all close for the exact build.

Effects not present here are still retained in the canonical timeline. The
runtime classifier returns an explicit mapped-unclassified or
unknown-unclassified result instead of filtering the event.
